What is the primary use case for the Medical RAG?
Clinician-facing decision support
   Doctors/nurses use it at point of care with cited evidence from guidelines, papers, drug labels
Patient-facing Q&A
  Consumers ask health questions in plain language, need safe triage and disclaimers
Internal document assistant
  Staff search internal SOPs, protocols, forms, and hospital policies
Clinical research / literature
   Researchers query papers, trial data, and drug databases for synthesis


Where will the medical data come from? 
Unstructured docs (PDFs, guidelines)
 Research papers, clinical guidelines, journal articles, drug labels as files
Structured clinical data
 EHR/claims records, lab results, ICD codes, FHIR resources from a database
Both, hybrid pipeline
Separate retrieval paths for unstructured docs vs structured rows, fused at answer time
Third-party medical APIs
Live sources like PubMed, DrugBank, RxNorm, clinical trial registries via API
